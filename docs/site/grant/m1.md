## Criterion 2: packages build and pass their tests

> `cip56-token` and `bridge-core` packages build and pass their unit + integration test suites against
> Canton mainnet, reproducibly from the repo.

### Build and test from source

Requires Daml SDK 3.4.8.

```bash
git clone https://github.com/ChainSafe/canton-erc20 && cd canton-erc20
git checkout v2.1.1           # the version vetted on MainNet and pinned by canton-middleware
./scripts/build-all.sh --daml-only
./scripts/test-all.sh
```
