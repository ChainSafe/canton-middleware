## Criterion 2: packages build and pass their tests

> `cip56-token` and `bridge-core` packages build and pass their unit + integration test suites against
> Canton mainnet, reproducibly from the repo.

### Build and test from source

Requires Daml SDK 3.4.8.

```bash
git clone https://github.com/ChainSafe/canton-erc20 && cd canton-erc20
git checkout 268ebe8          # commit pinned by canton-middleware v0.10.0
./scripts/build-all.sh --daml-only
./scripts/test-all.sh
```

### Deployed package IDs on MainNet

The MainNet participant vets `2.0.0` of each package. These IDs rebuild exactly from canton-erc20
commit [`e98a7db`](https://github.com/ChainSafe/canton-erc20/commit/e98a7db):

| Package | Version | Package ID |
|---|---|---|
| `common` | 2.0.0 | `c4d8bc62b74dfb93c0feda15cbceb5db16aef37d0e7ee37c17887faa9cbd33b9` |
| `cip56-token` | 2.0.0 | `c8c6fe7c34d96b88d6471769aae85063c8045783b2a226fd24f8c573603d17c2` |
| `bridge-core` | 2.0.0 | `be290fc1304d9a221def6e04a291368600599c9265f58f942a2b80478c348fca` |
| `bridge-wayfinder` | 2.0.0 | `6fac182df4943e7e2f70360b413b6e3ab10e65289ba0d971978b6d861a860d72` |

To reproduce:

```bash
git checkout e98a7db
./scripts/build-all.sh --daml-only
for p in common cip56-token bridge-core bridge-wayfinder; do
  daml damlc inspect-dar --json daml/$p/.daml/dist/$p-2.0.0.dar | jq -r .main_package_id
done
```

`2.1.0` (commit `268ebe8`) changes only the version numbers in each `daml.yaml`; the Daml code is
identical, so it produces different package IDs for the same code:

```bash
git diff e98a7db 268ebe8 -- daml/common daml/cip56-token daml/bridge-core daml/bridge-wayfinder
```
