## Criterion 2: packages build and pass their tests

> `cip56-token` and `bridge-core` packages build and pass their unit + integration test suites against
> Canton mainnet, reproducibly from the repo.

### Build and test from source

Requires Daml SDK 3.4.8.

```bash
git clone https://github.com/ChainSafe/canton-erc20 && cd canton-erc20
git checkout v2.1.1           # the version vetted on MainNet and pinned by canton-middleware
./scripts/build-all.sh --daml-only
./scripts/test-all.sh
```

### Deployed package IDs on MainNet

The MainNet participant vets `2.1.1` of each package. New commands run on 2.1.1, because the services
reference packages by name (`#cip56-token`) and Canton resolves a name to the highest vetted version.
Contracts created before the upgrade keep the `2.0.0` package they were created with.

| Package | 2.1.1 (current) | 2.0.0 (existing contracts) |
|---|---|---|
| `common` | `774bfc61c2fe7d5f472106a2539518a5d4d8093dd90456355783500f330ca1f4` | `c4d8bc62b74dfb93c0feda15cbceb5db16aef37d0e7ee37c17887faa9cbd33b9` |
| `cip56-token` | `b17adfeb9c93c73cbf914314751ce3a994974b629e5d425dd623775e8e6d35df` | `c8c6fe7c34d96b88d6471769aae85063c8045783b2a226fd24f8c573603d17c2` |
| `bridge-core` | `baf2d5ef49e7b35f221b489feed3670dcb7e92ed5007587e85282c4027ae5f25` | `be290fc1304d9a221def6e04a291368600599c9265f58f942a2b80478c348fca` |
| `bridge-wayfinder` | `ab8f35674c9502b3b85a44ddbc61082479327d24269b8eb08e6db44754f8404d` | `6fac182df4943e7e2f70360b413b6e3ab10e65289ba0d971978b6d861a860d72` |

Both sets rebuild exactly from source:

```bash
for build in v2.1.1:2.1.1 e98a7db:2.0.0; do     # <git ref>:<package version>
  ref=${build%%:*} ver=${build##*:}
  git checkout -q "$ref" && ./scripts/build-all.sh --daml-only > /dev/null
  for p in common cip56-token bridge-core bridge-wayfinder; do
    echo "$p $ver $(daml damlc inspect-dar --json daml/$p/.daml/dist/$p-$ver.dar | jq -r .main_package_id)"
  done
done
```

The 2.1.1 DARs are also published with checksums, so they can be checked without building:

```bash
for f in common-2.1.1.dar cip56-token-2.1.1.dar bridge-core-2.1.1.dar bridge-wayfinder-2.1.1.dar SHA256SUMS; do
  curl -fsSLO "https://github.com/ChainSafe/canton-erc20/releases/download/v2.1.1/$f"
done
sha256sum -c SHA256SUMS      # macOS: shasum -a 256 -c SHA256SUMS
```

The Daml code is the same across 2.0.0, 2.1.0 and 2.1.1. The later versions change only the version
numbers and add SPDX license headers, which is why the package IDs differ:

```bash
git diff e98a7db v2.1.1 -- daml/common daml/cip56-token daml/bridge-core daml/bridge-wayfinder
```
