# Grant verification

These pages map each Development Fund milestone
([proposal #453](https://github.com/canton-foundation/canton-dev-fund/pull/453)) to its acceptance
criteria and give, for each criterion, the evidence and a way to check it yourself without access to
ChainSafe infrastructure.

| Milestone | Claim issue | Page |
|---|---|---|
| M1: Architecture and Daml / bridge contracts | [#920](https://github.com/canton-foundation/canton-dev-fund/issues/920) | [M1](./m1) |
| M2: Middleware service (Ethereum JSON-RPC API) | [#921](https://github.com/canton-foundation/canton-dev-fund/issues/921) | [M2](./m2) |

Each page lists:

- **Criterion**: quoted from the claim issue.
- **Evidence**: what was delivered, with links pinned to commits.
- **Verify it yourself**: commands and their expected output.

Items marked _pending_ are being prepared and will be added here.
